# 03. 부캉이 모델 제작 파이프라인

부캉이 = 흉상어(Carcharhinus, 구리상어/흑기흉상어 계열). 형태 기준 사진은 `assets/concept/bukangi/reference-shark-photo.png`

## 좌표와 매개변수

- 모델 좌표: 미터, **+Y 위, +Z 정면, +X 오른쪽.** 헤엄치는 바인드 포즈에서 +Z 는 주둥이 방향.
- 몸 매개변수 **u** = 주둥이 끝 0 → 꼬리 끝 1 (전장 TL 비율). **h** = 몸 축 기준 높이(TL 비율). 단면 각도 **θ**: 0 = 오른쪽, π/2 = 등, −π/2 = 배.
- `toModel(x, h, u)` 이 TL 비율 → 미터 변환. `TOTAL_LENGTH = 2.8 m`, `U0 = 0.4` (z=0 이 되는 u).

## 1. 사진 → 랜드마크

사진은 정측면이 아니므로 **윤곽을 그대로 쓰지 않는다.** 쓰는 값은 이것뿐이다:

- 몸 높이: 윗선 12곳·아랫선 11곳에서 ±0.01 구간의 **중앙값** (`TOP_STATIONS`, `BOTTOM_STATIONS`). 아랫선은 사진 속 입이 살짝 벌어진 턱 구간(u 0.07~0.15)을 뺀다.
- 표식: 눈 위치·반지름, 아가미구멍 5개 위치·위아래 끝, 입꼬리, 각 지느러미 시작점, 꼬리 시작 (`measurements.landmarks`).
- 지느러미 끝점·꼬리 위 엽 끝·갈래 위치 (설계 행과 `CAUDAL` 에 숫자로 옮겨 적음).

측정을 다시 하려면 [05-quality-gates.md](05-quality-gates.md#사진-측정-다시-하기). 측정 스크립트의 좌표 상수는 **이 사진 전용**이다. 다른 사진을 쓰면 다시 읽어야 한다.

## 2. 설계 곡선 (`sharkAnatomy.ts`)

- **윗선·아랫선:** `h = tip ± A·u^p·(1−u)^q`. 매개변수 3개라 랜드마크 잡음을 따라 출렁일 수 없다. 꼬리자루로 넘어가는 곳에서만 곡률 부호가 한 번 바뀐다.
- **꼬리 위 엽 (heterocercal):** 척추가 이어지는 몸의 연장. 앞전은 살짝 오목한 선(t^1.15), 뒷전은 갈래에서 끝까지 곧은 선. `CAUDAL` 상수.
- **폭:** 사진에서 안 보이므로 흉상어 일반 해부 비례로 `반폭 = (0.86 + 0.55·e^(−u/0.12)) × 반높이` (머리 납작 → 몸통 0.9 → 꼬리자루 0.86). 이 비율을 1.76 까지 키우면 주둥이 옆 가장자리가 칼날처럼 휘어 얼룩말 줄이 한 선으로 몰렸다.
- **단면은 타원 하나.** 지수를 등·배로 나누거나 θ 로 분기하지 않는다 (D-07: 분기선이 구김으로 보였다).

> 형태를 고칠 때 규칙: **새 함수를 smoothstep 으로 이어 붙이지 말고**, 기존 곡선의 매개변수나 랜드마크를 바꾼다. 고친 뒤 곡률 검사를 돌린다.

## 3. 제어 케이지 (`sharkCage.ts`)

- **링:** `RINGS` 23개 (u, 등 쪽 값). 머리 링 2~6 은 배 쪽에서 입 선을 따라 휜다 (아래 '입'). 지느러미 뿌리 면의 앞뒤 경계가 링에 오도록 골랐다 (가슴 0.315–0.37, 첫 등 0.37–0.49, 배 0.53–0.59, 둘째 등·뒷 0.675–0.725, 꼬리 아래 엽 0.785–0.845). 지느러미를 옮기려면 링도 같이 옮긴다.
- **둘레:** `COLS = 32`. 면 중심이 등(90°)·배(270°)·옆구리 아래(±22.5°, ±67.5°)에 오도록 반 칸 어긋난다 (`colTheta`).
- **끝 덮개:** 주둥이·꼬리 끝은 극점(한 점에 모이는 부채꼴) 대신 **8×8 격자 덮개**. 바깥 링을 테두리로 쓰고 안쪽 점은 링 단면을 줄인 포물면 위에 둔다 (Shirley 동심 사상).
- **지느러미:** 뿌리 면 하나를 지운 뒤 설계 행(`FINS[].rows`: 날개 좌표 s, 앞전·뒷전 시위 위치, 앞전 두께)을 따라 고리 4점씩 밀어내고 끝을 덮는다.
  - 외곽은 사진 외곽이 아니라 **설계 행(조절점)** 이다. 앞전 조절 다각형이 한 방향으로만 꺾이게 둔다 → 곡률 부호 0.
  - 단면은 앞전이 두껍고 뒷전이 얇은 익형 (`TRAIL_THICKNESS = 0.3`).
  - 정중선 지느러미(등·둘째 등·뒷·꼬리 아래 엽)는 x=0 평면. 짝지느러미(가슴·배)는 `pairedFrame(날개 방향, 윗면 힌트)`.
  - 짝지느러미는 `collar`: 뿌리 면 바깥으로 먼저 짧게 나간 고리를 두고 두께 방향만 좁힌다 (뿌리에서 비틀리거나 나팔처럼 벌어지지 않게).
- **체색:** 케이지 정점의 `tint` 속성으로 서브디비전을 따라 같이 나뉜다. 몸은 최종 정점 위치에서 `bodyColor(u, sinθ)` 를 다시 계산해 경계를 또렷하게 한다.

## 4. 서브디비전 (`catmullClark.ts`)

- 정점 순서를 `[원래 정점, 모서리 점, 면 점]` 으로 둬서 케이지 정점 i 는 몇 번을 나눠도 인덱스 i 다.
- `fitCageToTargets(cage, targets, levels, iterations, fit)`: 한계면이 목표점을 지나도록 케이지를 반복 보정. **몸은 맞추지 않고(근사) 지느러미 정점만 맞춘다.**
  간격이 고르지 않은 링을 정확히 지나게 맞추면 보간 스플라인처럼 배선이 출렁였다(부호 4회). 근사는 조절점보다 더 출렁이지 않는다.
- 법선은 한 메시 전체의 면적 가중 평균이라 몸–지느러미 이음매가 없다.

## 5. 표면 (`createBukangiModel.ts`, `skinMaps.ts`)

- **눈자리:** 메시 정점을 실제로 밀어 오목하게 판다 (`eyeSocket`). 눈알은 구에 동공·은회색 홍채를 그린 텍스처, 35% 만 드러나게 묻는다.
- **정체 디테일은 맵으로:** 아가미구멍 5개, 입꼬리 주름, 콧구멍(+피부판), 눈꺼풀(아몬드형), 꼬리 앞 오목. 메시 해상도보다 가는 홈이라 형상이 아니라 노멀·그늘 맵(2048×4096, UV = (θ, u))으로 굽는다.
  지느러미 쪽은 `detailMask` 속성으로 맵을 끈다 (셰이더 패치, 적용 실패 시 콘솔 경고).
- **넣지 않는 것:** 노이즈 피부결, 감각공 점, 옆줄, 얼룩. D-07 에서 곰보로 보였다.
- **UV 이음매:** 배 정중선. 이음매를 가로지르는 삼각형은 정점을 복제해 b 를 1 넘어로 잇는다 (`splitSeam`).
- **재질:** `MeshPhysicalMaterial`, 꼭짓점 색 × 그늘 맵, 거칠기 0.4 고르게, 클리어코트 0.15 (젖은 막).
- **체색:** 등 꼭대기 진한 구릿빛 회색(`DORSAL_TOP`) → 옆면 밝은 은회색(`FLANK`) → 흰 배(`VENTRAL`). 흰 배 경계는 단면 높이 S≈−0.5 에서 또렷하게.
  옆구리 흰 띠는 가슴지느러미 뒤에서 앞으로 뾰족한 쐐기. 지느러미 끝은 어둡게(`DUSKY`), 등지느러미·꼬리 아래 엽은 뒷전 테두리도 어둡게. 색은 sRGB 값을 `^2.2` 로 선형화해 쓴다.

## 5½. 입 (`sharkMouth.ts`, `sharkCage.ts` 의 `buildMouth`, `sharkTeeth.ts`)

입은 맵의 선이 아니라 **케이지의 실제 틈 + 안으로 들어가는 주머니**다. 몸과 같은 한 장의 Catmull-Clark 메시라 입술이 둥글게 말려 들어가고 이음매가 없다.

- **입 선:** 배 정중선에서 잰 각도 φ 의 식 `u(φ) = 앞끝 + (구석 − 앞끝)·(sin|φ| / sinφc)^1.7` (앞끝 0.066, 구석 = 사진 랜드마크 u 0.147).
  구석 φc 는 랜드마크에 가장 가까운 둘레 정점 각도로 맞춘다 (구석이 케이지 정점이어야 틈이 거기서 끝난다). 지금 구석 사이 둘레 9칸.
- **링 휘기:** 입 링(`MOUTH_RING` = 0.11)은 배 쪽에서 입 선 자체가 되고, 앞 두 링·뒤 두 링은 입 선과 이웃 링 사이를 고르게 나눈 값으로 휜다.
  등 쪽 u 와 배 쪽 u 를 φ 로 섞는데(구석에서 옆구리 위 70° 까지), 두 목록이 각각 순서가 맞아서 섞어도 링이 엇갈리지 않는다.
- **틈:** 입 링의 두 구석 사이 정점을 복제한다. 앞쪽 면 = 위 입술(원본), 뒤쪽 면 = 아래 입술(복제본). 구석 두 정점은 공유.
- **주머니:** 틈 테두리 고리에서 행 5개를 안으로 밀어내 목구멍(u 0.19)에서 n각형으로 닫는다.
  잇몸 행(위는 입술에서 0.6% TL 안·조금 앞, 아래는 0.45% 안·조금 뒤) → 아래턱 피부를 τ 만큼 들인 바닥 / 그 위 cav 만큼의 천장. 뒤로 갈수록 좌우를 좁힌다.
  색은 케이지 `tint` (잇몸 분홍 → 입천장 → 검붉은 목구멍), `inner` 속성으로 맵·체색을 끈다.
- **턱 뼈:** 관절 = 두 입 구석을 잇는 x 축 → 구석은 벌려도 움직이지 않는다 (찢어짐 없음). 가중치는 케이지 `jaw` 속성(아래 입술·아래 벽 1, 구석 0.5, 아래턱 피부 1 → 목 쪽 0.45 → 0)을 서브디비전이 부드럽게 나눈 값.
- **이빨:** 잇몸 행 케이지 정점의 한계 위치(나눠도 인덱스가 같다)를 잇는 곡선을 따라 위 26개·아래 24개. 위는 넓은 삼각형(끝이 구석 쪽으로 기움), 아래는 좁은 송곳. 앞이 크고 구석이 작다. 가장 가까운 잇몸 정점의 스키닝을 복사해 잇몸과 똑같이 움직인다.
- **검사:** 곡률 검사의 배 정중선은 입 안(`inner > 0`)을 빼고 입 앞끝에서 끊는다. 뷰어 `?jaw=40` 으로 벌린 입을 본다 (`pose=swim` 에서도 된다).

## 6. 운동화 (`sneaker.ts`)

뒤꿈치 z=0 → 앞코 z=0.32 m, 바닥 y=0 의 로컬 좌표로 만들고 `createSneaker(1.8)` 로 키운다.
파란 갑피(sheen), 흰 중창, 회색 밑창, 흰 끈 5줄, 발목 칼라, 옆면 스우시형 흰 띠(앞이 굵고 둥글고 뒤꿈치 위로 가늘게).
칼라가 꼬리 아래 엽 끝을 감싸도록 놓고 꼬리 뼈(u≈0.83)에 붙인다. 밑창에 접지점 3개(뒤꿈치·가운데·앞코)가 있다.

## 만들면서 배운 것

| 증상 | 원인 | 해결 |
|---|---|---|
| 지느러미 뿌리가 혹·소매처럼 두꺼움 | 둘레 16점이면 뿌리 면(22.5°)이 약 7 cm 로 지느러미보다 두꺼움 | `COLS = 32` |
| 배선이 출렁임 (곡률 부호 4회) | 비균등 링을 한계면 보간 | 몸은 근사, 지느러미만 맞춤 |
| 배지느러미가 비틀림 | 두께 방향을 손으로 정함 | 뿌리 면의 둘레 방향(`across`)에서 계산 |
| 짝지느러미 뿌리가 나팔 모양 | 고리를 시위·두께 모두 줄임 | 두께 방향만 40% 좁힘 |
| 주둥이 끝 원뿔·꼭지 | 덮개 안쪽 점을 몸 단면에 그대로 둠 | 링 단면을 줄인 포물면 (작은 꼭지는 아직 남음) |
| 얼룩말 렌더에 가짜 수렴점 | equirect 줄무늬 환경맵의 극점 | 반사 방향 y 성분으로 줄을 그리는 셰이더 |
| 서 있는 자세 얼룩말 렌더가 헤엄 자세로 나옴 | 셰이더에 스키닝 블록이 없음 | `skinning_*` include 추가 |
| 정면에서 거의 흰색 | 체색 경계가 너무 높음 | 경계 S≈−0.5 |

## 고칠 때 체크리스트

1. 바꾼 것이 곡선·랜드마크·설계 행인가? (사진 픽셀이나 노이즈를 형상에 넣고 있지 않은가?)
2. `npm run check` — `pass: true`, 곡률·접지 수치 확인.
3. 얼룩말 렌더(측면·3/4·위·아래) → 회색 조명 확대(주둥이·아가미·입·눈·지느러미 뿌리·꼬리·신발) → 바다 조명 순서로 본다.
4. 헤엄 자세 실루엣 IoU ≥ 0.9.
5. `spec/assessment.json` 의 `reviewLog` 에 무엇을 왜 바꿨는지 한 줄.
