# 01. 프로젝트 개요

## 게임

- 제목(가제): **푸바오가 늑구와 세로를 찾아 부캉이를 타고 돌아오는 격투게임**
- 장르: 1:1 대전 격투. 상단·중단·하단, 약·강공격, 필살기, 가드, 잡기가 있는 일반적인 격투게임 문법.
- 플랫폼: **웹 브라우저** (Three.js + TypeScript + Vite). 결정 이유는 [02-decisions.md D-02](02-decisions.md#d-02-플랫폼-웹-threejs).
- 카메라: 2.5D(3D 모델이 2D 평면에서 싸움, 스트리트 파이터 6 방식). 연습 모드(`practice.html`)를 이 방식으로 만들었다(D-18). 각도·거리는 아직 사용자 확정 전이다.

## 플레이어블 캐릭터

| 캐릭터 | 동물 | 상태 | 비고 |
|---|---|---|---|
| 부캉이 | 흉상어 (구리상어/흑기흉상어 계열) | **모델·뼈대·대기 동작 완료** | 팔다리 없이 지느러미로 싸움. 꼬리 아래 엽에 파란 운동화 |
| 푸바오 | 자이언트판다 | 미착수 | 두 발로 설 수 있어 사람형 뼈대에 가장 가까움 |
| 늑구 | 늑대 | 미착수 | |
| 세로 | 얼룩말 | 미착수 | |

"푸바오·세로·늑구"는 국내 동물원에 실존하는(했던) 동물의 이름이다 (푸바오는 에버랜드 판다).
**개인·포트폴리오 프로젝트로 진행 중이며, 상업 출시라면 이름·외형 사용 권리를 따로 확인해야 한다.**
철권 판다 이미지는 분위기 참고로만 받았고 디자인(리본·팔찌 등)은 가져오지 않는다.

## 확정된 방향

1. **사실감 = A안 (철권식 반의인화).** 피부·털·비율·체색은 현실적으로, 자세와 움직임만 격투용으로 과장한다.
2. **모든 캐릭터는 서 있는다.** 상어도 서 있게 한다(사용자 결정).
3. **부캉이는 실제 팔다리가 없다.** 가슴지느러미 = 팔, 배지느러미·꼬리 = 다리(사용자 결정).
4. **부캉이는 몸을 굽히지 않고 꼿꼿이 선다.** 꼬리 위 엽 끝과, 아래 엽에 신긴 운동화 두 점으로 선다.
   운동화는 밈 "트랄랄레로 트랄랄라"의 파란 운동화이고, 옆면에 스우시처럼 보이는 흰 띠가 있어도 된다(사용자 결정).
5. **3D 모델은 코드로 만든다 (절차적 모델링).** 외부 3D 에셋·AI 3D 생성 없이 Three.js 코드로 형상을 만든다.
6. **작업은 AI 에이전트(Claude Code)가 한다.** 그래서 도구·검사·문서가 전부 코드와 텍스트로 재현 가능해야 한다.

## 품질 목표

- "상어로 읽히는가"(정체)와 "현실적인가"(표면·접합)를 따로 본다.
- 매끈함은 감으로 판단하지 않고 **수치(곡률 부호 바뀜)와 얼룩말 반사**로 잰다. 상세는 [05-quality-gates.md](05-quality-gates.md).
- 사용자가 먼저 결함을 찾아내는 일이 없게, 고친 뒤에는 반드시 확대·여러 방향 렌더로 직접 확인한다.
