# 04. 뼈대와 동작

## 뼈대 (`src/characters/bukangi/sharkRig.ts`)

- **척추:** 몸 축 위 0.03 TL 간격 **33개** (`SPINE_STATIONS`, u 0.02~0.98). 뿌리 뼈는 u=0.44(무게중심 근처)이고 여기서 앞 사슬(머리 쪽)과 뒤 사슬(꼬리 쪽)이 뻗는다.
- **짝지느러미:** 가슴(팔)·배(발) 좌우마다 뿌리·중간·끝 3마디. 가장 가까운 척추 뼈에 붙는다.
- **아래턱:** `jaw` 뼈. 두 입 구석을 잇는 x 축이 관절이고 u 0.14 척추 뼈에 붙는다. 가중치는 케이지 `jaw` 속성 (03 문서 '입').
- **가중치:** 몸 정점은 척추 위치 u 에 대한 **균일 3차 B-스플라인(뼈 4개)**. 처음엔 이웃 뼈 2개 선형이었는데 큰 굽힘에서 등이 접혔다.
  짝지느러미 정점은 지느러미 2마디 + 척추 2개 (영향 4개 한도), 뿌리에서 몸 가중치로 부드럽게 넘어간다.
- **바인드 포즈 = 헤엄치는 자세.** 눈은 머리 뼈에, 운동화는 꼬리 뼈(u≈0.83)에 붙어 있다.

### 뼈 로컬 축의 뜻 (헷갈리기 쉬움)

뿌리 뼈를 −90° 가까이 돌려 세우면 축의 의미가 이렇게 된다 (`sharkAnimator.ts` 가 부호를 처리한다):

| 뼈 로컬 축 | 서 있을 때 | 앞 사슬 회전 + | 뒤 사슬 회전 + |
|---|---|---|---|
| x | 앞뒤 굽힘 | 머리가 앞(배 쪽)으로 | 꼬리가 뒤(등 쪽)로 |
| y | 옆 굽힘 (상어가 헤엄칠 때 흔드는 방향) | 머리가 오른쪽(+x)으로 | 꼬리가 **왼쪽**으로 |
| z | 몸 축 비틀기 | | |

큰 굽힘은 `bendRegion(rig, from, to, 총각도, 축)` 으로 구간 안 뼈들에 sin² 모양으로 나눈다. **한 뼈에 큰 각도를 몰지 않는다.**

## 서 있는 자세 = 두 점 접지

몸은 굽히지 않는다. 뿌리 뼈의 기울기만 풀어서 **꼬리 위 엽 끝과 운동화 밑창이 같은 높이**가 되게 한 뒤, 가장 낮은 점을 바닥(y=0)에 놓는다.
처음 운동화를 놓을 때는 `solveStandingTilt`(굳은 몸 회전식), 동작 중에는 애니메이터가 매 프레임 실제 뼈 자세로 다시 푼다(이분법, 지난 해 근처부터).

## 애니메이터 (`src/characters/bukangi/sharkAnimator.ts`)

`animator.apply(channels)` 가 한 프레임의 포즈를 적용한다. 순서:

1. 뼈 초기화 → 척추 구간 굽힘 적용
2. `support > 0` 이면 두 점이 함께 닿는 기울기를 풀고, 자유 기울기(`tilt`)와 `support` 비율로 섞는다
3. 지느러미 겨누기: 기본 자세 대비 **부모 뼈가 돈 만큼 같이 돌린 방향**을 겨눈다 (몸이 기울면 팔도 따라감)
4. 발 방향 고정: `support > 0` 이면 꼬리를 옆으로 굽혀 틀어진 꼬리 끝→신발 방향만큼 몸 전체를 되돌린다 (발은 그대로, 윗몸이 돈다)
5. 접지: 가장 낮은 접지점(꼬리 끝·신발·**몸 겉면 240곳·지느러미 끝 7곳**)을 `hop` 높이에, 고정점(신발 또는 꼬리 끝)을 기본 자리 + `slide`/`tailSlide` 에 앞뒤·좌우 모두 고정 (`anchor`)

### 채널 (전부 0 이 기본 서 있는 자세, 각도는 도, 길이는 m)

| 채널 | 뜻 |
|---|---|
| `tilt` | 몸 전체 기울기 (+ = 앞으로 숙임). `support=1` 이면 무시됨(두 점 해가 정함) |
| `sink` | 바닥 아래로 잠기는 깊이 (m). 접지를 푼 뒤 몸 전체를 내린다. 바닥 아래는 그리지 않는다 (잠수 강습) |
| `lean` | 몸 전체를 옆으로 넘어뜨리기 (+ = 오른쪽). 앞 방향 축 회전이라 서 있으면 발 선을 축으로 옆으로 눕고, 뒤로 누워 있으면(tilt ≈ −96) 몸 축을 따라 구른다 |
| `turn` | 몸 전체를 세로축으로 돌리기 (도, 고정점을 축으로). −180~180 으로 접고 `(1 − support)` 만큼만 적용 — 두 발로 딛고는 돌 수 없다. 꼬리 쓸기처럼 360 까지 키를 잡아도 된다 |
| `support` | 1 = 두 점 접지 유지 / 0 = 풀지 않음 (킥·점프처럼 한 점이나 공중일 때) |
| `hop` | 가장 낮은 접지점 높이 (점프·깡총) |
| `slide` | 신발을 고정할 앞뒤 위치 (+ = 앞). 걷기·대시의 이동 거리 |
| `tailSlide` | 꼬리 위 엽 끝을 고정할 앞뒤 위치 (`anchorTail=1` 일 때) |
| `anchor` | 1 = 고정점을 바닥에 고정 (미끄러지지 않게) |
| `anchorTail` | 고정점 선택: 0 = 신발, 1 = 꼬리 위 엽 끝 (신발 킥처럼 꼬리로 버틸 때) |
| `headPitch/Side/Twist` | 머리 구간 (u 0~0.24). Pitch + = 앞으로 숙임, Side + = 오른쪽, Twist = 비틀기 |
| `trunkPitch/Side/Twist` | 몸통 구간 (u 0.22~0.44) |
| `tailPitch/Side` | 꼬리 구간 (u 0.55~0.8). Pitch + = 꼬리가 뒤로, Side + = 오른쪽. 꼬리 끝을 딛고(`anchorTail=1`) Pitch + 를 주면 꼬리지느러미 전체가 꼬리 끝을 축으로 돌아 **신발이 들린다** (신발 킥) |
| `tailTipPitch/Side` | 꼬리 끝 구간 (u 0.79~1.0) |
| `pecR/L_yaw, _pitch, _elbow, _elbowYaw` | 가슴지느러미(팔). yaw + = 바깥으로, pitch + = 위로, elbow = 끝마디 추가 각도 |
| `pelR/L_yaw, _pitch, _knee` | 배지느러미(발) |
| `jaw` | 입 벌림 (도, + = 벌림). 관절은 두 입 구석을 잇는 선. 50° 가 크게 벌린 입 |

주의:
- 몸이 굳은 막대라 `support=1` 에서 몸 전체를 숙이고 싶으면 `tilt` 가 아니라 `trunkPitch`/`headPitch` 로 낸다 (발 쪽 접지에 영향이 없다).
- **두 접지점 사이 거리는 고정이다.** 한 점을 축으로 돌리면 다른 점은 원을 그릴 뿐이라, 한쪽이 미끄러지지 않고는 앞으로 갈 수 없다.
  그래서 걷기는 신발이 바닥을 끌고(의도된 미끄러짐) 꼬리는 들었다 딛는다. 꼬리 끝 구간을 굽혀 거리를 바꾸려는 시도는 꼬리 끝이 위로 들리기만 해서 버렸다.
- 바닥을 딛은 채로 `slide` 를 바꾸면 두 점이 함께 미끄러진다. 움츠림(anticipation)에서 뒤로 물러나는 동작은 넣지 않는다.
- `support`·`anchor`·`anchorTail` 은 0~1, `hop` 은 0 이상으로 애니메이터가 잘라낸다.

## 동작 만들기 (`src/characters/bukangi/moves.ts`)

```ts
export const IDLE: PoseClip = {
  name: 'idle',
  length: 80,          // 60fps 프레임
  loop: true,
  keys: [
    { f: 0,  pose: { trunkPitch: 0, pecR_pitch: 0 } },
    { f: 20, pose: { trunkPitch: 5, pecR_pitch: 11 }, ease: 'smooth' },  // 'smooth'(기본, 넘치지 않는 3차) | 'linear' | 'hold' | 'in' | 'out'
    …
  ],
};
export const CLIPS = { idle: IDLE, … };  // 여기 넣으면 뷰어 타임라인 목록에 뜬다
```

- 키에 적지 않은 채널은 **앞 키 값을 이어받는다** (첫 키는 `NEUTRAL`).
- 기본 보간 `smooth` 는 **넘치지 않는 3차 보간**(기울기 제한형, auto-clamped). Catmull-Rom 은 착지 뒤 `hop` 이 0 아래로 넘쳐 몸이 바닥을 뚫었다.
  같은 값이 이어지는 키 사이는 평평하게 머문다 — 발을 딛고 있는 구간은 이동 채널을 같은 값으로 두 키 이상 적으면 된다.
- 반복 클립은 마지막 키에서 첫 키로 이어 보간한다. 첫 키는 `f: 0` 에 둔다.
- **제자리로 돌아오지 않는 반복**(걷기)은 `rootMotion`(반복 한 번의 전진 거리)을 적고, 마지막 키를 `f: length` 에 두고 이동 채널을 그만큼 앞선 값으로 적는다.
  다음 반복은 그만큼 옮긴 자리에서 0 으로 시작한다 (뷰어는 4번 반복마다 제자리로 돌린다).
- 반복하지 않는 클립은 뷰어에서 끝에 40프레임 멈췄다가 다시 재생한다.
- 공격은 `moves.ts` 의 `MOVES` 에 `{ clip, hitboxes }` 로 적는다 (`src/fighting/frameData.ts`).
  판정 구는 `{ socket, radius, frames: [시작, 끝], height, damage }` — frames 는 클립 프레임(0 부터, 끝 포함).
  **발생·지속·회복은 적지 않는다.** `moveFrames()` 가 판정에서 계산한다 (발생 = 첫 판정 프레임 번호, 1 부터 세는 격투게임 표기 "i9").
  판정 기준점(소켓): `snout`, `pecR-tip`, `pecL-tip`, `tail-tip`(꼬리 위 엽 끝), `shoe`(신발 밑창 가운데), `bite`(입 가운데 바로 바깥, 위턱을 따름) (`animator.sockets`).
  여러 번 때리는 기술은 판정을 여러 개 적는다. 지속은 판정이 켜진 프레임만 센다 (사이 빈 프레임 제외).
  피격 캡슐: `snout`, `head`, `trunk`, `tail`, `caudal`(꼬리지느러미), `shoe`. 주둥이 캡슐은 앞끝을 반지름만큼 물려 주둥이 끝을 넘지 않는다.

### 동작 검토 절차

1. 뷰어에서 재생, ◀ ▶ 로 키 근처를 한 프레임씩 본다. **판정** 버튼으로 피격 캡슐(파랑)과 공격 판정(빨강, 지속 프레임에만)을 같이 본다.
   공격 클립은 타임라인 글자에 `발생 · 지속 · 회복 [지금 구간]` 이 뜬다. 카메라는 몸통을 따라간다 (**따라가기** 버튼, `follow=0`).
2. `npm run check` 의 `motion.<클립>`:
   - `maxGap`: support=1 프레임에서 두 접지점 높이 차 (< 1 mm)
   - `tailSkate`: 꼬리 끝이 두 프레임 연속 바닥에 닿은 동안 미끄러진 최대 거리 (< 1 mm)
   - `shoeSkate`: 신발의 같은 값. **걷기의 끌기에서만** 0 이 아니어도 된다
   - `minY`: 가장 낮은 접지점 (≥ 0)
   - 미끄러짐은 바닥 위 앞뒤·좌우 거리다
   - 원인을 찾을 때는 `npm run check -- '&trace=<클립>'` → 프레임별 `[f, tailY, shoeY, tailX, tailZ, shoeX, shoeZ, support, anchorTail]`
   - 공격은 `attacks.<클립>`: 발생·지속·회복, 지속 프레임 동안 판정 구의 높이 `y: [아래, 위]`, 앞으로 닿는 거리 `reach`
   - 자세를 설계할 때는 `npm run check -- '&probe=<URL 인코딩한 채널 JSON>'` → 그 자세의 소켓·접지점 좌표 (`probe`).
     예: `{"support":0,"anchorTail":1,"tailPitch":45}` 로 신발이 얼마나 들리는지 본다
3. 키 프레임을 `?anim=<이름>&frame=N&shot=1` 로 찍어 시트로 묶어 본다 ([05-quality-gates.md](05-quality-gates.md)).
4. 굽힘이 큰 동작은 `mode=zebra` 로 굽은 곳의 구김을 본다.

| `hit-high` | 28f | 상단·중단 피격. 머리가 뒤로 꺾이고(−38°) 입이 벌어지며 지느러미가 튐, 두 발이 붙은 채 0.14 m 밀려남(`skid` 1–10f) → 가드 자세로 |
| `hit-low` | 30f | 하단 피격. 발이 걷어차여 앞으로 고꾸라지며 깡총 뜨고 0.14 m 밀려남(공중) → 신발부터 딛고 복귀 |
| `guard-high` | 23f | 서서 막기. 몸을 비틀어 어깨를 넣고 두 가슴지느러미를 앞으로 접어 올림, 충격에 눌리며 0.07 m 밀려남(`skid` 4–10f) |
| `guard-low` | 26f | 앉아 막기. 몸통·머리를 깊이 숙여(주둥이 약 2.0 m) 지느러미로 아래 앞을 가림, 0.07 m 밀려남(`skid` 5–11f). 앉은 자세로 시작해 앉은 자세로 끝난다 (앉아야 막을 수 있어서) |
| `crouch` | 60f 반복 | 앉기. 앉아 막기와 같은 웅크린 자세에서 숨 쉬듯 들썩임. 두 점 접지 그대로 (7단계에서 추가) |
| `knockdown` | 56f | 다운. 윗몸이 젖혀지고 → 뒤로 날아가며(정점 0.42 m, 꼬리 끝 0.7 m 뒤로) 구름 → 왼 옆구리를 대고 배를 보이며 떨어짐 → 두 번 튐 → 늘어짐 |
| `down` | 60f 반복 | 누워 있기. 몸은 그대로, 위쪽 지느러미·꼬리 끝·턱만 힘없이 움직임 |
| `wake-up` | 48f | 기상. 꼬리로 바닥을 쳐 뜨며 등 쪽으로 구름 → 꼬리 끝을 축으로 몸을 세움 → 신발을 딛고 가드 자세로 |

누운 자세(`LIE`): `tilt −96, lean −80, tailSide −4`, 바닥 쪽 왼 가슴·배지느러미를 배 쪽으로 접음. 몸통 옆구리(u 0.3 근처)와 꼬리 위 엽 끝이 함께 바닥에 닿는다.
다운·기상은 꼬리 끝을 고정점으로 쓴다(`anchorTail 1`). 기상 끝에서 신발 목표(`slide`)를 꼬리와 같은 거리(−0.7)로 맞춰 둔 뒤 고정점을 신발로 돌린다 — 다르면 바꾸는 순간 몸이 튄다.

### 경직·가드 (`src/fighting/frameData.ts`)

판정마다 `hitstun`(맞은 쪽 경직), `blockstun`(막은 쪽 경직), `knockdown`(다운 여부)을 적는다.
- `frameAdvantage(move)`: 이득 프레임 = 상대 경직 − 판정이 첫 지속 프레임에 닿은 뒤 공격 쪽이 남은 프레임. 여러 번 때리면 마지막 판정 기준.
  `chainOnHit`/`chainOnBlock` = 앞 판정의 경직이 다음 판정까지 이어지는지.
- `blocks(guard, height)`: 서서 막기 = 상단·중단, 앉아 막기 = 하단 (D-16).
- `reactionFor(hit, guard, REACTIONS)`: 받는 쪽이 재생할 클립과 경직. 상단·중단 피격 → `hit-high`, 하단 → `hit-low`, 다운 판정 → `knockdown`.

| 기술 | 경직 (맞음 / 막음) | 이득 (맞음 / 막음) |
|---|---|---|
| `fin-jab` | 19 / 16 | +2 / −1 |
| `tail-sweep` | 다운 / 18 | 다운 / −13 |
| `shoe-kick` | 33 / 26 | +3 / −4 |
| `rising-bite` | 32 / 20 | +2 / −10 |
| `twist-tear` | 1타 14 / 12 → 2타 다운 / 20 | 다운 / −12 (1타 경직이 2타까지 이어짐) |

자세 설계: `?set={채널 JSON}` 으로 그 자세 하나에 멈춰 찍는다. `probe` 결과에 바닥에 가장 가까운 소켓 5개(`low:<이름>`)가 나온다 — 누운 자세에서 무엇이 몸을 받치는지 찾을 때.
