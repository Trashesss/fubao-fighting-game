# 06. 로드맵과 알려진 문제

## 부캉이 동작 단계 (D-12 에서 합의)

각 단계 끝(✋)에서 사용자 확인을 받는다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 애니메이션 시스템, 뷰어 타임라인, 대기 동작 ✋ | ✅ 완료 (`f52ffb9`) |
| 2 | 이동: 걷기(신발로 끌듯이), 대시(꼬리로 깡총), 후진, 점프 ✋ | ✅ 걷기·후진·대시·점프·앞 점프 (`2617342`) |
| 3 | 물기 없는 기술 + 판정: 지느러미 잽(약), 꼬리 쓸기(하단), 신발 킥 ✋ | ✅ 세 기술 + 판정 표시·검사, 카메라 따라가기 (`b4e689b`) |
| 4 | 턱 뼈 + 입 안·잇몸·이빨 모델링 → 솟구쳐 물기(상단), 비틀어 물어뜯기(강) ✋ | ✅ 입 틈·주머니·턱 뼈·이빨 50개, 두 물기 기술 (사용자 확인 대기) |
| 5 | 피격(상·하), 가드(상·하), 다운, 기상 ✋ | ✅ 7개 반응 클립, 경직·이득 프레임·가드 규칙, 몸 접지점 (`d4236c4`) |
| 6 | 필살기: 잠수 강습 (바닥으로 잠수 → 등지느러미만 보이며 접근 → 솟구치기) | ✅ sink 채널·바닥 클리핑·바닥 물결 효과·무적 구간 (사용자 확인 대기) |
| 7 | 연습 모드: 부캉이 두 마리 2.5D 대결로 프레임·판정 검증 | ✅ `practice.html`, 게임 루프·밀어내기·자동 검사, 킥·잽 사거리 수정 (D-18) |

그 뒤: 푸바오(사람형에 가장 가까움) → 늑구 → 세로. 공통 시스템(포즈 클립, 판정, 검사 도구)은 재사용하고, 캐릭터마다 해부 곡선·케이지·뼈대·애니메이터를 만든다.

## 알려진 문제 (형태는 "나중에 또 고치자"로 보류 중)

| 문제 | 위치 | 메모 |
|---|---|---|
| 키 약 2.56 m (목표 약 2.1 m) | `TOTAL_LENGTH = 2.8` | 몸을 안 굽혀서 전장이 거의 키가 됨. 전장을 줄이면 맞지만 상어가 작아짐 → 사용자 결정 필요 |
| 꼬리지느러미 실루엣 겹침이 가장 낮음 (0.814) | `CAUDAL`, 꼬리 아래 엽 설계 행 | 위 엽 끝 엽(terminal lobe)·아래쪽 갈래 모양이 사진보다 단순 |
| 주둥이 끝 작은 꼭지 | 끝 덮개 (`cap`) | 덮개 모서리 정점(가지 3개) 의심, 미확인 |
| 배지느러미가 조금 크고 노 모양 | 배지느러미 설계 행 | |
| 좌우로 불안정해 보임 | 서 있는 자세 | 두 접지점이 앞뒤로만 벌어짐. 배지느러미를 바닥 쪽으로 내리면 세 번째 지지점 |
| 위턱이 앞으로 나오지 않음, 이빨 한 줄·톱니 없음, 혀 없음 | `sharkMouth.ts`, `sharkTeeth.ts` | 물 때 위턱 내밀기는 사실감에 효과가 큼. 필요하면 위 입술·잇몸 행에 두 번째 뼈 |
| 대기 동작 들썩임이 작음 | `moves.ts` | 몸이 굳은 막대라 두 점 접지를 지키면 크게 못 흔듦. 사용자 승인 상태 |

## 남은 결정 (사용자)

- 푸바오 키: 지금 정수리 1.70 m (실제 판다가 서면 약 1.5~1.6 m). 부캉이 2.56 m 와의 차이
- 푸바오 기술 구성 (P3·P5 의 예시는 제안일 뿐)

- 부캉이 키 (전장 줄이기 여부)
- 2.5D 카메라: 연습 모드에서 시야각 28°·정측면으로 진행 중 (D-18). 각도·거리 조정 여부
- 판정 높이 기준 (상·중·하단 높이를 캐릭터마다 어떻게 둘지 — 지금은 부캉이 기준값만 `05-quality-gates.md` 에 있다).
  부캉이는 앉아도 주둥이가 약 2.0 m 라 상단 기술이 앉은 부캉이에게도 닿는다 (D-16)
- 가드 규칙: 지금은 철권식(앉아 막기는 중단에 맞음). 스트리트 파이터식(앉아 막기가 중단도 막음)으로 바꿀지
- ~~다운 방향~~: 왼쪽을 보는 쪽을 좌우로 뒤집어 그려 해결 (D-18)
- 각 기술의 세부 연출은 단계별 확인 때
